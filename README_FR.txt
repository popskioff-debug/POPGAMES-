POPGAMES — paquet préparé pour mise en ligne PWA
1. Publie tous les fichiers de ce dossier sur un hébergement HTTPS (par exemple GitHub Pages).
2. Ouvre l'adresse publique du site et teste les jeux.
3. Va sur PWABuilder.com, colle l'adresse HTTPS, puis suis les étapes Android pour générer le paquet.
Limites : le jeu 3D charge encore Three.js depuis un CDN, donc la première ouverture du jeu 3D demande Internet. La génération d'un APK via PWABuilder peut dépendre de la configuration de l'hébergement et des options choisies. Ce dossier n'est pas un APK.
